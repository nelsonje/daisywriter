daisywriter

Mail merge onto a daisywheel typewriter

Write a letter in Word, list the people it goes to in Excel, and daisywriter types a copy for each of them on your typewriter, with their name, address and anything else filled in. It shows each letter exactly as it will be typed, and remembers which ones are done.

Download for Windows Download for Mac

This early version isn't signed yet, so installing it takes a couple of extra clicks:

  • Windows:
    1. The web browser may warn that the file “isn't commonly downloaded”. To keep it in Microsoft Edge, point at the file in the downloads list, click …, then Keep (and if asked, Show more, then Keep anyway). In Chrome, click Keep.
    2. Open the downloaded file to install daisywriter.
    3. If Windows says “Windows protected your PC”, click More info, then Run anyway.
  • Mac (Apple silicon: M1 or later): open the downloaded file and drag daisywriter onto Applications. The first time, macOS won't open it: open System Settings > Privacy & Security, scroll down, and click Open Anyway.

What you need

  • A Swintec 1146 CMP, Swintec 1146 CM or Olympia Electronic Compact 2 typewriter.
  • A USB-to-parallel printer cable (with a Prolific PL2305 chip) to connect it. There's nothing else to install, and no printer to set up.
  • Word and Excel, or another program that saves .docx and .xlsx files.

About

daisywriter is a hobby project by Jacob Nelson, made to put electronic daisywheel typewriters back to work. It's open source under the MIT license: free to use, change and share, with no warranty.

The source code is on GitHub, where you can also report a problem or suggest something.
