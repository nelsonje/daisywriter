Sabrent's USB-to-parallel cable works too.

### Downloads
- **Windows:** `daisywriter-0.1.6-windows-x64.msi`. It replaces an earlier
  version if one is installed. Your browser and Windows may warn about it,
  because the installer isn't signed yet: see
  [installing](https://daisywriter.jfet.net/#download).
- **Mac** (Apple silicon): `daisywriter-0.1.6-macos-arm64.dmg`. Not signed yet,
  so the first time use **System Settings > Privacy & Security > Open Anyway**.
- **Sample letters:** `daisywriter-0.1.6-samples.zip`.

The [user guide](https://daisywriter.jfet.net/#guide) is also in the app under
**Help > daisywriter User Guide** (F1).

### Changes
- **Sabrent's USB-to-parallel printer cable** works as well as cables with a
  Prolific PL2305 chip, on Windows and Mac. daisywriter uses whichever one is
  plugged in, with any of the typewriters; there's still nothing to install.
- The command line's `status` names the cable it found; in the window, point at
  the status next to **Check typewriter** to see it.
- If no cable is found, the message now lists both kinds it looked for.

### Known limits
- Only the Swintec 1146 CMP and 1146 CM, and the Olympia Electronic Compact 2,
  so far.
- Paper wider than letter can't use the extra width yet.
- The installers aren't signed.
