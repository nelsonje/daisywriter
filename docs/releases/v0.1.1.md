Fixes from the first tests with the typewriter on Windows.

### Downloads
- **Windows:** `daisywriter-0.1.1-windows-x64.msi`. It replaces 0.1.0 if that's
  installed. Windows will warn that the publisher is unknown, because the
  installer isn't signed yet: click **More info**, then **Run anyway**.
- **Mac** (Apple silicon): `daisywriter-0.1.1-macos-arm64.dmg`. Not signed yet,
  so the first time use **System Settings > Privacy & Security > Open Anyway**.

The [user guide](https://github.com/nelsonje/daisywriter/blob/main/src/daisywriter/gui/user_guide.md)
is also in the app under **Help > daisywriter User Guide** (F1).

### Changes
- **Stop** says what happens: the typewriter still types the line or two it
  already has, so a letter stopped part way through now gets a message to take
  the sheet out and print it again on a fresh one.
- Pulling the USB cable while typing now says *"the adapter stopped responding:
  is the USB cable unplugged?"* instead of a Windows error message.
- `daisywriter status` exits with status 1 when the typewriter isn't ready, and
  reports a failed status read instead of crashing.
- New: `daisywriter probe` measures how far ahead of the typewriter the adapter
  takes data, for making Stop quicker in a later version.

### Known limits
- Stop takes effect a line or two late.
- Only the Swintec 1146 CMP and Olympia Electronic Compact 2 so far.
- The installers aren't signed.
