Stop now stops when the line being typed is finished, and sample letters to try.

### Downloads
- **Windows:** `daisywriter-0.1.2-windows-x64.msi`. It replaces an earlier
  version if one is installed. Windows will warn that the publisher is unknown,
  because the installer isn't signed yet: click **More info**, then **Run anyway**.
- **Mac** (Apple silicon): `daisywriter-0.1.2-macos-arm64.dmg`. Not signed yet,
  so the first time use **System Settings > Privacy & Security > Open Anyway**.
- **Sample letters:** `daisywriter-0.1.2-samples.zip`. A letter in Word and a
  list of five people in Excel, to try daisywriter before making your own.
  Unzip it; its `README.txt` says which files to choose.

The [user guide](https://github.com/nelsonje/daisywriter/blob/main/src/daisywriter/gui/user_guide.md)
is also in the app under **Help > daisywriter User Guide** (F1).

### Changes
- **Stop** takes effect when the line being typed is finished. Before, the
  typewriter went on to type two more lines.
- Sample letters with each release.
- A template with `{{body}}` markers no longer warns that they're incomplete
  placeholders.

### Known limits
- Only the Swintec 1146 CMP and Olympia Electronic Compact 2 so far.
- The installers aren't signed.
