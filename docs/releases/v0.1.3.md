Sample letters from the Help menu.

### Downloads
- **Windows:** `daisywriter-0.1.3-windows-x64.msi`. It replaces an earlier
  version if one is installed. Your browser and Windows may warn about it,
  because the installer isn't signed yet: see
  [installing](https://daisywriter.jfet.net/#download).
- **Mac** (Apple silicon): `daisywriter-0.1.3-macos-arm64.dmg`. Not signed yet,
  so the first time use **System Settings > Privacy & Security > Open Anyway**.
- **Sample letters:** `daisywriter-0.1.3-samples.zip`.

The [user guide](https://daisywriter.jfet.net/#guide) is also in the app under
**Help > daisywriter User Guide** (F1).

### Changes
- **Help > Open Sample Letters** opens a sample letter and its list of people,
  and puts them in a *daisywriter samples* folder in Documents. Files already
  there are kept.
- The Olympia's profile is now called `olympia-electronic-compact-2` (for
  `--profile` on the command line), after the machine's full name.

### Known limits
- Only the Swintec 1146 CMP and Olympia Electronic Compact 2 so far.
- The installers aren't signed.
