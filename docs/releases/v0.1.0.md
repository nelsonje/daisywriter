The first test release of daisywriter: mail merge from Word and Excel onto a
daisywheel typewriter (Swintec 1146 CMP or Olympia Electronic Compact 2,
connected with a USB-to-parallel cable).

**This is an alpha.** It works on the machine it was developed with, but it's
new: keep an eye on the first few letters, and please report anything odd.

### Downloads
- **Windows:** `daisywriter-0.1.0-windows-x64.msi`. Windows will warn that the
  publisher is unknown, because the installer isn't signed yet: click
  **More info**, then **Run anyway**.
- **Mac** (Apple silicon): `daisywriter-0.1.0-macos-arm64.dmg`. Not signed yet,
  so the first time use **System Settings > Privacy & Security > Open Anyway**.

### Getting started
The [user guide](https://github.com/nelsonje/daisywriter/blob/main/src/daisywriter/gui/user_guide.md)
covers installing, setting up the typewriter, writing the letter in Word,
making the list in Excel, and printing. It's also in the app under
**Help > daisywriter User Guide** (F1).

### What's in it
- The letter list, issues and a preview that matches what's typed
- Printing on the typewriter, or on an emulator that makes a PDF
- Bold, underline, strikethrough, alignment, indents and tabs from Word
- Optional typing errors with typewriter-style corrections
- It remembers which letters were printed, so you can stop and carry on later

### Known limits
- Only the Swintec 1146 CMP and Olympia Electronic Compact 2 so far.
- Printing from Windows is new: it has been tested with Windows itself, but not
  yet at length with the typewriter.
- The installers aren't signed.
